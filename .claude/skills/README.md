# Skills du projet

Copier ici les skills utiles depuis `Documents/ressources/agent-skills-library/skills/`
(1 dossier par skill contenant un `SKILL.md`), chargés à la demande — ne pas dupliquer la
logique d'un skill existant, le copier tel quel.

Avant de créer un nouveau skill : consulter `audit-mes-skills.md` (racine `Projets/`) pour éviter
un doublon avec un skill global ou d'un autre projet.

Anatomie d'un skill : voir `agent-skills-library/docs/skill-anatomy.md`.

Supprimer ce README dès qu'un vrai skill est copié dans ce dossier.
